# Đêm Diễn Tri Ân NSND Kim Cương

Website giới thiệu chương trình **Đêm Diễn Tri Ân Khán Giả – NSND Kim Cương**.

## Xem website

Mở trực tiếp `index.html` hoặc chạy một web server tĩnh tại thư mục dự án.

## Nội dung chính

- Hành trình sân khấu của NSND Kim Cương
- Thông tin chương trình tri ân
- Nhật ký ảnh tư liệu tại Hoa Viên Bình Dương
- Giao diện responsive cho mobile, tablet và desktop
